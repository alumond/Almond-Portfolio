# Tests

## Test 1 - Portfolio introduction and primary work path [sanity]
Viewport: desktop
Covers: welcome introduction, hero layout, primary call to action, scroll motion system
Description: Confirms the portfolio opens with its branded introduction and gives visitors a clear path into selected work without overlapping content.

Steps:
1. Open the portfolio in a fresh tab
2. Wait for the welcome introduction to finish
3. Select "See selected work"

Expected: The selected-work section becomes visible, the hero copy and controls do not overlap, and page sections reveal as the page scrolls.

## Test 2 - Professional metrics and data visualization
Viewport: desktop
Covers: animated metrics, data charts, responsive statistics layout

Steps:
1. Scroll to "What I bring"
2. Review all three metric cards

Expected: The values 25, 30%, and 4+ are clearly visible with distinct labels, supporting text, and charts contained inside their cards.
